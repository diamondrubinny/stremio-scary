# SCARY Web כאפליקציית Android

**מה זה:** אותה אפליקציית Web, ארוזה בתוך APK ומוצגת ב-WebView. קובץ אחד לטלפון, לטאבלט ול-Android TV
(מופיעה גם במסך הבית של הטלוויזיה). Android 8.0 ומעלה. הקוד: `android/`.

## איך זה בנוי

| נושא | ההחלטה | למה |
|---|---|---|
| מאיפה נטענת האפליקציה | מהקבצים שבתוך ה-APK (כ-990 קבצים, כולל הקטלוגים) | עובדת בלי אתר מתארח, ונפתחת גם בלי רשת (תמונות ופרטי סרטים דורשים רשת) |
| הכתובת בתוך ה-WebView | `https://appassets.androidplatform.net/` (`WebViewAssetLoader`) | כתובת מאובטחת שקיימת רק בתוך האפליקציה, כך שהאחסון וההצפנה (ה-PIN) עובדים כמו באתר |
| קישורים חיצוניים (IMDb, חנויות, קוד המקור) | נפתחים בדפדפן של המכשיר | ה-WebView מציג רק את האפליקציה עצמה |
| שמירת קובץ גיבוי | הדף מבקש מהאפליקציה, והאפליקציה שואלת את המשתמש איפה לשמור | ב-WebView אין "הורדה"; הערוץ פתוח רק לדפים של האפליקציה עצמה (`WebMessageListener` מוגבל ל-origin) |
| שחזור מקובץ | בורר הקבצים של המערכת | |
| מסך מלא בנגן | נתמך; המסך נשאר דלוק והסרגלים מוסתרים | |
| הרשאות | `INTERNET` בלבד | |
| גיבוי ענן של Android | כבוי | הספרייה, הרשימות וה-PIN לא עוזבים את המכשיר |
| HTTP לא מוצפן | חסום, חוץ מ-`127.0.0.1` | שרת הסטרימינג של Stremio, אם הוא רץ על אותו מכשיר |

הגרסאות (Gradle, AGP, SDK 37, minSdk 26, webkit) זהות לאלה של SCARY ל-Android TV.

## בנייה

```bash
(cd feed && npm run build)            # הקטלוגים
(cd web && pnpm install && pnpm build) # אפליקציית ה-Web
(cd android && ./gradlew :app:assembleDebug)
# android/app/build/outputs/apk/debug/app-debug.apk
```
ב-GitHub: ה-workflow ‏"Android" בונה, מריץ lint ושומר את ה-APK כ-artifact (אחרי שמפעילים Actions בריפו).

## חתימה

בלי מפתח — ה-APK נחתם במפתח debug של המכונה שבנתה אותו, ולכן **APK ממכונה אחרת לא יתקין מעל הקודם** (צריך להסיר
ולהתקין). כדי שכל בנייה תתעדכן מעל הקודמת: להוסיף לריפו את הסודות `SCARY_KEYSTORE_BASE64`, `SCARY_KEYSTORE_PASSWORD`,
`SCARY_KEY_ALIAS`, `SCARY_KEY_PASSWORD` (אותו מנגנון כמו ב-SCARY הנייטיב). **לא להשתמש במפתח של SCARY הנייטיב** בלי
החלטה מודעת — זו אפליקציה נפרדת (`io.github.diamondrubinny.scary.web`).

## מה נבדק ומה לא

- ✔ נבנה כאן בפועל: debug ‏(18MB) ו-release עם R8 ‏(13.7MB); lint של Android: 0 שגיאות.
- ✔ תוכן ה-APK נבדק: כל קובצי האפליקציה והקטלוגים בפנים (כולל שמות עם `=` ו-`&`), בלי source maps; פעילות אחת
  שמופיעה גם בלאנצ'ר וגם ב-Android TV; הרשאת `INTERNET` בלבד.
- ✗ **לא הורץ על מכשיר או אמולטור** (בסביבת הבנייה אין האצת וירטואליזציה). כל מה שתלוי בזמן ריצה לא אומת: טעינה
  ב-WebView, ניווט בשלט של טלוויזיה, בורר הקבצים, שמירת הגיבוי, מסך מלא, סיבוב מסך.

## מגבלות ידועות

- **ניגון:** מה ש-WebView יודע לנגן (MP4/HLS וכדומה). טורנטים דורשים את שרת הסטרימינג של Stremio על אותו מכשיר.
- **הקטלוגים ארוזים ב-APK**, ולכן מתעדכנים רק עם גרסה חדשה של האפליקציה (באתר הם מתעדכנים כל שבוע).
- **WebView ישן:** האפליקציה צריכה WebView עדכני (מתעדכן דרך חנות האפליקציות). על מכשיר שלא עודכן שנים היא עלולה לא לעלות.
- **שלט בטלוויזיה:** Stremio Web תומך בניווט במקשי חיצים, אבל זה לא נבדק כאן על טלוויזיה.
