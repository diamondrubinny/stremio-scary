# מדיניות פרטיות — SCARY Web (טיוטה)

> **טיוטה טכנית.** מתארת את מה שהאפליקציה עושה בפועל (נבדק בקוד ובבדיקות רשת, 26.11.2026). **מחייבת בדיקה משפטית
> לפני פרסום**, כולל התאמה לחוק הגנת הפרטיות (ותיקון 13) ול-GDPR. פרטי בעל השליטה ואיש הקשר: **[להשלים]**.

## בקצרה
- **אין חשבון, אין הרשמה, אין התחברות.**
- **אין אנליטיקה, אין פרסום, אין פיקסלים, אין מעקב.**
- **אין לנו שרת.** האפליקציה היא קבצים סטטיים; כל מה שאתם שומרים נשאר בדפדפן (או באפליקציית ה-Android) שלכם.
- שני דברים בלבד דורשים את הסכמתכם, ושניהם כבויים עד שתאשרו: **טריילרים מ-YouTube** ו**חיפוש קולי**.

וממפתחות ה-AI**. הקובץ אינו מוצפן: שמרו אותו במקום שרק אתם מגיעים אליו.

## למי הדפדפן שלכם פונה
בכל פנייה הצד השני רואה את כתובת ה-IP שלכם ואת סוג הדפדפן, כמו בכל אתר.

| למי | מתי | מה נשלח |
|---|---|---|
| ספק האירוח של האתר — GitHub Pages (GitHub, Inc., ארה"ב) | בטעינת האפליקציה | בקשות לקבצי האפליקציה ולקטלוגים |
| Cinemeta ו-metahub (Stremio / Smart Code OOD) | כשמוצגים פוסטרים ופרטי סרט; ברשימות האימה/מתח/מסתורין של Cinemeta; כשטריילר עומד להתנגן מעצמו (אחרי אישור YouTube) | מזהי הסרטים (IMDb) |
| WatchHub (Stremio) | בעמוד סרט | מזהה הסרט |
| OpenSubtitles (תוסף של Stremio) | בזמן ניגון | מזהה הסרט והשפה |
| שרת הסטרימינג של Stremio **במכשיר שלכם** (`127.0.0.1`), אם התקנתם אותו | בעלייה ובזמן ניגון | פנייה מקומית בלבד; לא יוצאת מהמכשיר |
| תוספים **שאתם** התקנתם | לפי התוסף | לפי התוסף — באחריות מי שמפעיל אותו |
| YouTube (Google) | **רק אחרי שאישרתם**: כשמתנגן טריילר, כולל טריילר שמתנגן מעצמו כשנחים על סרט (אפשר לכבות בהגדרות) | מה ש-YouTube אוסף לפי מדיניותו, כולל עוגיות שלו |
| שירות הדיבור של הדפדפן (ב-Chrome: Google) | **רק אחרי שאישרתם**, בזמן חיפוש קולי | ההקלטה |
| שירות AI שבחרתם (ברירת מחדל: Pollinations; או OpenAI, Anthropic, Google, Groq, OpenRouter, Mistral, DeepSeek, או שירות משלכם) | **רק אחרי שאישרתם**, כשאתם שואלים ב"שאלו את SCARY" או לוחצים "על הסרט" | מה שהקלדתם; רשימת סרטים מהמאגר לבחירה, או פרטי הסרט (שם, שנה, סוגים, תקציר); המפתח שלכם אם הוספתם; ורק אם הפעלתם זאת — שמות של עד 12 סרטים שאהבתם |
| TMDB | **רק אם הוספתם מפתח משלכם** | המפתח ומזהי הסרטים שאתם פותחים |

**מה חסום בכוונה:** האפליקציה חוסמת מבפנים פניות לשירותי החשבון של Stremio (`api.strem.io`, `www.strem.io`,
`link.stremio.com`) — כולל איתור מיקום לפי IP, תצורה מרחוק והודעות קידום — ואת הקטלוגים הכלליים של Cinemeta.
**מה שאתם מחפשים לא נשלח לאף אחד:** החיפוש רץ בדפדפן, על המאגר של SCARY.

## הזכויות שלכם
הכול אצלכם: אפשר לראות, לייצא (קובץ גיבוי) ולמחוק (ניקוי נתוני האתר בדפדפן) בלי לפנות אלינו. את ההסכמה אפשר לשנות
בכל רגע ב"הגדרות SCARY" ← "פרטיות ותוכן חיצוני". לפניות: **[להשלים]**.

## שירותי AI
"שאלו את SCARY" כבוי עד שתשתמשו בו ותאשרו את השירות בשמו. הבקשה יוצאת מהדפדפן שלכם ישירות לשירות — אין שרת של SCARY
באמצע — והשירות פועל לפי מדיניות הפרטיות שלו, בדרך כלל מחוץ לישראל ולאיחוד האירופי. אל תקלידו פרטים אישיים. מפתח שנשמר בדפדפן
חשוף לכל מי שמשתמש בדפדפן ולתוספי דפדפן. **דורש בדיקה משפטית.**

## פרופילים
פרופילים הם נוחות ולא נעילה: כל מי שמשתמש בדפדפן יכול לפתוח כל פרופיל ולראות את הרשימות שלו, חוץ מיציאה מ"פרופיל עדין",
שדורשת את קוד ההורים כשהוגדר. שם של בן בית הוא מידע אישי; אנחנו מבקשים שם בלבד (בלי גיל, תמונה או דוא"ל) והוא לא יוצא מהדפדפן.

## קטינים
SCARY Web מציגה תוכן אימה. יש "ערב משפחתי" ונעילת הורים, אבל הן פועלות בדפדפן ואינן תחליף להשגחה. **[גיל מינימלי — לבדיקה משפטית]**

## נושאים לבדיקה מקצועית
בסיס חוקי לכל עיבוד; מעמדנו מול Stremio, Google ו-TMDB; העברת מידע מחוץ לישראל/לאיחוד; חובת רישום מאגר (להערכתנו אין
מאגר, לאימות); נוסח לקטינים; פרטי בעל השליטה.
