# הפיצ'רים של SCARY הנייטיב ב-SCARY Web

**החלטת הבעלים (26.11.2026): להוסיף הכול.** המסמך הזה הוא התוכנית והמצב. הכללים מועתקים מהקוד של SCARY ל-Android TV
(`core/.../catalog`, `core/.../security`), והמחרוזות — מ-`strings.xml` שלו, בחמש השפות.

## ארכיטקטורה (שכבת SCARY בלבד, `web/src/scary/`)

| תיקייה | מה יש בה |
|---|---|
| `domain/` | לוגיקה טהורה ונבדקת: נעילה ו-PIN, מצבי רוח ועשורים, תכנון זמן, המלצות, רשימות, סטטיסטיקה, עונות |
| `state/` | `store.ts` — מה שנשמר בדפדפן (`localStorage["scary.state"]`, נקרא כקלט לא מהימן); `session.ts` — מה שחי רק בזמן הביקור (PIN שהוזן, טיימר שינה); `backup.ts` — קובץ גיבוי |
| `content/` | המאגר (`feed/index.json`), הקטלוגים, החיפוש |
| `ui/` | הרכיבים: מד פחד, תוספות לבית ולעמוד הסרט, שכבות-על, דף ההגדרות, דפי SCARY |
| `i18n/` | `native.ts` — המחרוזות של הנייטיב; `strings.ts` — מחרוזות ייחודיות ל-Web |

הכול מקומי: שום דבר מהרשימות, מהנעילה או מההיסטוריה לא נשלח לשום מקום.

## מגבלות ידועות

- **הנעילה היא בצד הדפדפן.** מי שמנקה את נתוני הדפדפן מסיר אותה; זה כתוב בהגדרות.
- **"השנה שלך בפחד"** סופר סרטים שנפתחו בנגן של SCARY Web, לא סרטים שסומנו "נצפה" בספרייה של Stremio.
- **פאנל התצוגה בגילוי** עדיין מציג רקע של סרט נעול (האריח עצמו מוסתר, והכניסה לסרט חסומה).
- **ניגודיות:** טקסט בצבע עצם על האדום של SCARY הוא כ-3.4:1 — לטיפול בשלב הנגישות.

## בדיקות

122 בדיקות (`web/tests/scary/`), רצות באותה רמת שפה כמו הבנייה. נבדק גם בדפדפן אמיתי: מצב רוח + סרט כפול, אהבתי +
Bucket list, יצירת PIN, שער הנעילה, קוד שגוי/נכון.

**תקלה שנמצאה ותוקנה בדרך:** הבנייה מתרגמת TypeScript ל-ES5, ושם פריסה של `Set`/`Map` נשברת בשקט (רשימות נשמרו
ריקות). נוסף `downlevelIteration` ל-`tsconfig.json`, והבדיקות רצות עכשיו באותה רמת שפה כדי לתפוס את זה.
